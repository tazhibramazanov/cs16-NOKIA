CS 1.6 — Nokia E52 Edition 1.0 — сервер мультиплеера
===================================================

Сервер нужен, чтобы игроки с телефонов и ПК находили друг друга по всему миру.
Он только подбирает комнату и пересылает данные. Ботами, раундами и уроном
управляет игра первого игрока в комнате (если он выйдет — роль сама перейдёт
к следующему). Файлы: cs16_server.py (Python 3, без библиотек) и start.sh.

БЕСПЛАТНЫЙ ХОСТИНГ serv00.com (сервер в Евросоюзе, работает 24/7)
  1. Зарегистрируйтесь на serv00.com (нужна только почта). В письме придут
     логин, пароль и адрес вашего сервера, например s7.serv00.com.
  2. Войдите в панель (DevilWEB, ссылка в письме):
     - «Additional services» → «Run your own applications» → Enabled;
     - «Port reservation» → «Add port» → тип TCP, порт Random → запомните номер
       (например 51234).
  3. Загрузите в домашнюю папку cs16_server.py и start.sh (панель → File manager,
     или по SSH/SFTP через WinSCP/FileZilla с теми же логином и паролем).
  4. Подключитесь по SSH (в Windows: cmd → ssh ЛОГИН@s7.serv00.com) и выполните:
        chmod +x start.sh
        ./start.sh 51234
     (вместо 51234 — ваш порт из пункта 2)
  5. Чтобы сервер сам поднимался после перезагрузок хостинга: панель → Cron jobs →
     Add cron job → каждые 5 минут (Specify time: Every 5 minutes), команда:
        /home/ЛОГИН/start.sh 51234 >/dev/null 2>&1
  6. Заходите в панель хотя бы раз в 90 дней — иначе serv00 удаляет аккаунт.

В ИГРЕ
  Мультиплеер → «Сервер» → введите адрес:порт, например  s7.serv00.com:51234
  (один раз на каждом телефоне/ПК — дальше запоминается). Потом выберите режим и
  карту и нажмите «Найти игру». Друзьям дайте тот же адрес.

ЕСЛИ serv00 НЕ ПОДОШЁЛ
  Скрипт запускается где угодно, где есть Python 3 и открытый TCP-порт:
  любой VPS, или ваш ПК (python cs16_server.py 27016 + проброс порта 27016 на
  роутере). Порт по умолчанию — 27016.

ПРОВЕРКА
  В файле server.log видно, кто зашёл/вышел и в какую комнату.
  Трафик: ~2–3 КБ/с на игрока (матч 10 минут ≈ 1,5 МБ).
