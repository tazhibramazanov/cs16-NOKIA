# CS 1.6 — Nokia E52 Edition

Свой движок, который запускает **Counter-Strike 1.6** на кнопочном **Nokia E52** (Symbian S60 3rd FP2, Java ME) и на Windows-ПК для проверки.

> В репозитории только код движка, конвертеры и сервер. Файлов игры (карт, моделей, звуков, текстур) здесь **нет**: они принадлежат Valve. Чтобы собрать игру, нужна ваша собственная копия Counter-Strike 1.6 (папки `cstrike/` и `valve/`).

## Возможности

- Программный 3D-рендер (BSP, z-буфер, освещение), карты **de_dust2**, **de_dust**, **de_train**
- Настоящие 3D-модели игроков и оружия в руках с анимациями
- Боты с навигацией по карте и уровнями сложности
- Режимы: **Оригинал** (бомба, раунды, закупка), **Дезматч**, **Зомби** (три типа зомби: Бегун, Громила, Ходок)
- Мультиплеер:
  - по всему миру, без своего сервера (через бесплатные публичные MQTT-серверы) или через свой сервер;
  - по LAN (Wi-Fi), без ввода адреса;
  - пустые места занимают боты, вошедший игрок встаёт вместо бота.
- Интерфейс в стиле оригинального меню CS 1.6, графика: Минимальная / Средняя / Высокая / Максимальная
- **Nokia FR и DLSS**: генерация кадров и динамическое разрешение для слабого телефона
- Вертикальный (240×320) и горизонтальный экран на телефоне, переназначение всех клавиш
- ПК-версия: клавиатура + мышь, одиночный `.exe` со встроенной Java

## Структура

| Папка | Что внутри |
|---|---|
| `src/core` | движок (общий для телефона и ПК, Java 1.3 / CLDC 1.1) |
| `src/midp` | обёртка для телефона (MIDP 2.0) |
| `src/pc` | обёртка для Windows (AWT) |
| `conv/` | конвертеры файлов CS 1.6 → форматы движка (Python 3) |
| `tools/` | сборка подписанного `.sisx`, упаковка `.exe` |
| `launcher/` | одиночный `.exe`-запускатель для Windows (C) |
| `server/` | сервер мультиплеера (Python 3, без библиотек) |

## Сборка

### 1. Что нужно

- Python 3 с `numpy` и `Pillow`
- JDK 11+ (для ПК-версии и запуска инструментов)
- Папка `lib/` с файлами:
  - `cldcapi11-2.0.4.jar`, `midpapi20-2.0.4.jar` (из MicroEmulator 2.0.4)
  - `ecj-4.6.1.jar` (компилятор Eclipse)
  - `proguard-base-7.4.2.jar`, `proguard-core-9.1.1.jar`, `log4j-api-2.19.0.jar`, `log4j-core-2.19.0.jar`, `kotlin-stdlib-1.9.0.jar`
- Для `.exe`: Zig (`pip install ziglang`) и папка `jre/` с Java для Windows
- Для `.sisx`: свой сертификат в `cert/` (см. `cert/README.md`)

### 2. Конвертировать файлы игры

```
CS16_GAME=/путь/к/папке/с/cstrike/и/valve ./convert.sh
```

### 3. Собрать

```
VER=1.0.0 ./build.sh        # телефон: build/CS16_E52.jar + .jad
python3 tools/build_sis.py  # телефон: build/CS16_E52.sisx
./build_pc.sh               # ПК: build/CS16_PC.jar
./build_exe.sh папка_с_jre_и_CS16_PC.jar CS16_E52_PC.exe
```

## Установка на Nokia E52

Скопируйте `CS16_E52.sisx` на телефон и откройте его, либо установите `CS16_E52.jar`.
Около 6 МБ, карта памяти не нужна.

## Мультиплеер

По умолчанию («Сервер: авто») игра сама находит соперников через бесплатные публичные MQTT-серверы. Свой сервер можно поднять командой `python3 server/cs16_server.py 27016` (подробнее в `server/README_сервер.txt`) и вписать его адрес в игре.

## Управление (телефон, по умолчанию)

| Клавиша | Действие |
|---|---|
| 2 / 8 / 4 / 6 | ходьба |
| джойстик | обзор |
| 5 / центр джойстика | огонь |
| 1 | прыжок |
| 3 | присесть |
| 7 | перезарядка |
| 0 | обезвредить / использовать |
| 9 | следующее оружие |
| * | прицел / глушитель |
| # | закупка |

Все клавиши можно переназначить: «Настройки» → «Клавиши».
